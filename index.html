Powerful Features, Reimagined

📝

Multiple Notes, One Page

No longer limited to a single note. Add as many Pebbles as you need to any webpage and organize your thoughts exactly how you see fit, without cluttering your browser window.

Cross-Website Notes

Create "Global Pebbles" that appear across every page you visit. Perfect for a universal scratchpad, list of bookmarks, or running code snippets. Marked by a globe icon.

Our dashboard popup is now expanded to a spacious 640px layout. Search list contents, filter by custom tags, and redirect instantly to the host page in a single click.

Personalize notes with 8 tailored colors. Features four classic templates and four brand-new themes (Sakura Pink, Ocean Breeze, Forest Sage, and Royal Plum) with dark-theme text contrast optimization.

Your notes are fully secure and private. All data is saved inside your browser profile's local storage and is never uploaded to external servers.

Backup & Restore

Easily protect your notes database. Export your collections to a portable JSON backup file and restore or import them on any machine in seconds.

Privacy Policy for PagePebble

Effective Date:

PagePebble ("we," "us," or "our") is committed to protecting your privacy. This Privacy Policy explains how PagePebble handles your information when you use our Chrome extension.

Information We Collect & Store

PagePebble is designed with your privacy as a priority. The extension stores the following information solely on your local computer using Chrome's local storage API (chrome.storage.local):

  • Note Content: The text and checklist data you type into your PagePebble notes.
  • Note Position & Size: Coordinates and dimensions defining where and how you place your notes on webpages.
  • Note Theme & Transparency: Your selected background color and opacity properties.
  • Tags: Customized tag labels applied to organize individual notes.

This information is stored strictly locally and is associated with the URL of the webpage where it was created.

Data Storage, Security, and Transmission

All data created and managed by PagePebble is stored locally within your web browser. This data is NEVER transmitted to, or stored on, any external servers. We do not have access to your notes, your browsing history, or any of the data PagePebble handles.

The security of your locally stored data depends entirely on the security of your computer profile and browser environment.

Your Control Over Your Data

You have full control over your stored notes:

  • You can edit, delete, or wipe notes at any time using the trash icon inside the note templates.
  • You can clear all notes globally or export your note database to a portable JSON backup file.
  • Uninstalling the PagePebble Chrome extension removes all local note storage data from your profile.

Permissions

PagePebble requires the following permissions to operate:

  • storage: To save note content, coordinates, themes, and configuration parameters locally.
  • activeTab & scripting: To inject the note editor user interface onto pages you interact with.

We only request permissions that are absolutely essential for the extension's core features.
